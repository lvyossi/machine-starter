# דף נחיתה פשוט

התוצר: קובץ `index.html` אחד בתיקיית פרויקט (`~/my-business/<שם-הדף>/`). כל העיצוב והקוד בתוך הקובץ. אפשר לפתוח אותו בדפדפן ולהעלות לאוויר עם הסקיל `publish`.

## 1. לפני שבונים

לקרוא את `business.md` אם קיים (סקיל business-profile). לשאול רק מה שחסר:
- **על מה הדף?** שירות אחד, מוצר אחד או אירוע אחד. דף אחד = מטרה אחת.
- **מה הפעולה שהגולש צריך לעשות?** לשלוח וואטסאפ, להתקשר או להשאיר פרטים.
- **יש תמונות?** לבקש תמונות אמיתיות של העסק. אם אין — דף בלי תמונות עדיף על תמונות מאגר שלא קשורות.

לסכם את התוכנית בכמה שורות ולקבל אישור לפני הכתיבה.

## 2. מבנה מומלץ

1. **ראש הדף** — כותרת שאומרת מה הלקוח מקבל (לא את שם העסק), משפט הסבר, וכפתור פעולה בולט.
2. **למה אנחנו** — שלוש נקודות קצרות.
3. **איך זה עובד** — שלושה צעדים.
4. **המלצות** — רק אמיתיות. אם אין, מדלגים על הסקשן.
5. **שאלות נפוצות** — שלוש עד חמש.
6. **קריאה לפעולה אחרונה** — אותו כפתור שוב.
7. **תחתית** — פרטי קשר.

## 3. כללים טכניים

- `<html lang="he" dir="rtl">` ופונט עברי מ-Google Fonts (ברירת מחדל: Heebo).
- צבעים מ-`business.md`, מוגדרים פעם אחת כמשתנים (`--main`, `--accent`).
- **קודם טלפון:** רוב הגולשים מגיעים מהנייד. כפתורים גדולים, טקסט קריא, בלי גלילה הצידה.
- **כפתור וואטסאפ:** `https://wa.me/9725XXXXXXXX?text=` עם הודעה מוכנה בקידוד URL, למשל "היי, הגעתי מהדף ואשמח לפרטים".
- **טופס בלי שרת:** שם + טלפון, ובשליחה פותח וואטסאפ לעסק עם הפרטים. לא לבקש יותר שדות ממה שצריך.
- `<meta name="viewport">`, כותרת ותיאור לדף (`<title>`, `og:title`, `og:description`) כדי שהשיתוף בוואטסאפ ייראה טוב.
- בלי טקסט עברי בתוך תמונות — כל הטקסט ב-HTML.

## 4. לבדוק לפני שמוסרים

- לפתוח את הדף בדפדפן ולהציג למשתמש.
- להקטין את חלון הדפדפן לרוחב של טלפון ולוודא שהכול קריא ושאין גלילה הצידה.
- ללחוץ על כפתור הוואטסאפ ולוודא שהוא נפתח עם המספר והטקסט הנכונים.

## 5. לסיים

לכתוב למשתמש: איפה הקובץ, איך פותחים אותו, ומה הצעד הבא — "רוצה להעלות לאוויר? (publish)".
