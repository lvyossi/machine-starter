# העלאה לאוויר

## 1. בדיקה לפני

- בתיקייה יש `index.html` (או פרויקט עם `package.json`).
- אין בתיקייה קבצים פרטיים: סיסמאות, `.env`, רשימות לקוחות, קבצי גיבוי. אם יש — להעביר אותם לתיקייה אחרת לפני ההעלאה.

## 2. העלאה ב-Vercel (חינם)

בפעם הראשונה:
```bash
npm i -g vercel
vercel login
```
המשתמש מתחבר בעצמו בדפדפן (מומלץ "Continue with GitHub" או מייל).

מתוך תיקיית הפרויקט:
```bash
vercel --prod --yes
```
- בפעם הראשונה נשאל שם הפרויקט. **השם הופך לכתובת:** `pilates-dana` → `pilates-dana.vercel.app`. שם קצר, באנגלית, בלי רווחים.
- לשלוח ללקוחות רק את הכתובת הקצרה (`https://<שם>.vercel.app`), לא את הכתובת הארוכה עם המספרים.

**עדכון:** אחרי כל שינוי מריצים שוב `vercel --prod --yes` מאותה תיקייה.

## 3. בדיקה אחרי

1. לפתוח את הקישור בחלון גלישה בסתר.
2. לפתוח גם בטלפון.
3. לשלוח את הקישור לעצמך בוואטסאפ ולראות שהתצוגה המקדימה (כותרת ותיאור) נראית טוב.
4. ללחוץ על הכפתורים ולוודא שהם עובדים.

## 4. דומיין משלך (אופציונלי)

אם יש לעסק דומיין: ב-Vercel → הפרויקט → Settings → Domains → מוסיפים את הדומיין, ו-Vercel מציג אילו רשומות להוסיף אצל החברה שממנה קנו אותו.
**זהירות:** אם על הדומיין יש כבר אתר או מייל — לא למחוק רשומות קיימות. בפרט לא לגעת ברשומות MX (מייל). אם לא בטוחים — לעצור ולשאול את מי שמנהל את הדומיין.

## 5. לסיים

לכתוב למשתמש: הקישור החי, איך בודקים, ואיך מעדכנים בפעם הבאה.
