# תמונות חינמיות לפרויקט

המשתמש כנראה לא מתכנת. לדבר בעברית פשוטה ולסכם, לא להדביק פלט ארוך.

## 0. קודם — יש תמונות של העסק?

תמונות אמיתיות של העסק עדיפות תמיד. לשאול פעם אחת: "יש לך תמונות משלך (מהטלפון או מהדרייב)? אם כן, תגרור את התיקייה לכאן." אם יש — לעבוד איתן. אם אין או שצריך עוד — להמשיך.

## 1. בפעם הראשונה: מפתח חינמי של Pexels

לבדוק אם יש מפתח: להריץ את הסקריפט (סעיף 2). אם הוא עונה `NO_KEY`:

1. להסביר במשפט: "Pexels הוא מאגר תמונות חינמי. כדי להוריד ממנו צריך מפתח חינמי, פעם אחת, לוקח שתי דקות."
2. לבקש מהמשתמש: להיכנס ל-https://www.pexels.com/api, להירשם (אפשר עם גוגל), וללחוץ על הכפתור לקבלת מפתח API. המפתח מופיע מיד.
3. **לא לבקש שידביק את המפתח בצ'אט.** ליצור (או לפתוח) את הקובץ `~/my-business/.env` עם השורה:
   ```
   PEXELS_API_KEY=<להדביק כאן את המפתח>
   ```
   לפתוח את הקובץ (`open` במק, `notepad` בחלונות) ולבקש: "תדביק את המפתח במקום הטקסט, תשמור ותסגור, ותכתוב לי 'שמרתי'".
4. לוודא שקובץ `.env` לא עולה לאינטרנט: אם יש בתיקייה `.gitignore`, להוסיף אליו `.env`.

**אין זמן או לא רוצים להירשם?** ממשיכים עם Openverse (`--source openverse`), בלי מפתח. להסביר: "חלק מהתמונות שם דורשות קרדיט לצלם. אני ארשום את זה."

## 2. להוריד

הסקריפט נמצא בתיקייה של הסקיל הזה: `get_images.py`. במק `python3`, בחלונות `python`.

```bash
python3 "<תיקיית הסקיל>/get_images.py" "<נושא באנגלית>" --count 10 --size web --out images
```

- **נושא באנגלית** — המאגרים מחפשים באנגלית. לתרגם את הבקשה ל-2–4 מילים מדויקות (למשל "תמונות לסטודיו פילאטיס" → `pilates studio reformer`). לקרוא את `business.md` אם קיים, כדי להבין את התחום.
- **גודל (`--size`)** לפי השימוש:
  | שימוש | `--size` | גודל |
  |---|---|---|
  | דף נחיתה / אתר | `web` | רוחב 1600 |
  | פוסט אינסטגרם/פייסבוק | `post` | 1080×1350 |
  | סטורי / ריל | `story` | 1080×1920 |
  | פוסט מרובע | `square` | 1080×1080 |
  | מצגת | `deck` | 1920×1080 |
- **`--out`** — תיקיית `images` בתוך הפרויקט שעובדים עליו.
- אם המשתמש לא אמר כמה: 10.

הסקריפט שומר את התמונות וכותב `images/sources.md` עם צלם, עמוד מקור ורישיון לכל תמונה.

## 3. להראות ולבחור

- להציג למשתמש את התמונות (לפתוח את התיקייה, או לבנות עמוד קטן עם כל התמונות ולפתוח בדפדפן) ולשאול אילו לשמור.
- **פנים:** בגדלים שנחתכים (`post`, `story`, `square`, `deck`) החיתוך הוא מהמרכז. לבדוק שאף פנים לא נחתכו. אם כן — להוריד שוב עם `--size web` ולחתוך בעצמך כך שהפנים בפנים.
- למחוק את התמונות שלא נבחרו, ולמחוק את השורות שלהן מ-`sources.md`.

## 4. כללים

- **Pexels:** חינם לשימוש מסחרי, בלי חובת קרדיט. לא להשתמש בתמונה כך שנראה שהאדם שבה ממליץ על העסק, ולא למכור את התמונה עצמה.
- **Openverse:** לפי הרישיון שרשום ב-`sources.md`. אם כתוב "חובה לתת קרדיט" — להוסיף בתחתית הדף או בכיתוב: "צילום: <שם הצלם>".
- תמונות עם לוגו של חברה אחרת או מותג מזוהה — לא לבחור.
- אף פעם לא להוריד תמונות מגוגל תמונות או מאתרים אחרים. רק מהמקורות האלה, או תמונות של המשתמש עצמו.
