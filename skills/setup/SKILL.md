# הכנת המחשב

המשתמש כנראה לא מתכנת. לדבר בעברית פשוטה, להסביר במשפט אחד למה צריך כל דבר, ולסכם פלט של טרמינל במקום להדביק אותו.

## 1. לבדוק מה קיים

מק:
```bash
for c in node npm git python3; do printf "%s: " $c; command -v $c >/dev/null && ($c --version 2>&1 | head -1) || echo "חסר"; done
```
חלונות (PowerShell):
```powershell
foreach($c in 'node','npm','git','python'){ $x=Get-Command $c -ErrorAction SilentlyContinue; "$c : " + $(if($x){ & $c --version 2>&1 | Select-Object -First 1 } else {'חסר'}) }
```

להציג טבלה: כלי · מותקן? · למה הוא צריך.

## 2. להתקין רק מה שחסר — אחרי אישור

| כלי | למה | מק | חלונות |
|---|---|---|---|
| Node.js | להריץ ולהעלות אתרים | הורדה מ-nodejs.org (גרסת LTS) | `winget install OpenJS.NodeJS.LTS` |
| Git | לשמור גרסות של העבודה | `xcode-select --install` | `winget install Git.Git` |
| Python | סקריפטים קטנים וניתוח קבצים | הורדה מ-python.org | `winget install Python.Python.3.12` |

- כל התקנה שדורשת סיסמה — המשתמש מקליד בעצמו. אף פעם לא לבקש סיסמה בצ'אט.
- בחלונות: אחרי התקנה לסגור ולפתוח מחדש את הטרמינל.

## 3. תיקיית עבודה

ליצור `~/my-business` (בחלונות: `%USERPROFILE%\my-business`) עם תת-תיקייה לכל פרויקט. להסביר: "כל פרויקט בתיקייה משלו, ופותחים את קלוד קוד מתוכה".

## 4. בדיקה קטנה שהכול עובד

ליצור בתיקייה קובץ `hello.html` עם כותרת "שלום!" בעברית מימין לשמאל, ולפתוח אותו בדפדפן (`open` במק, `start` בחלונות).

## 5. לסיים

טבלה קצרה: מה מותקן, מה נוצר. אם משהו נכשל פעמיים — לעצור ולהציע לפנות למדריך, לא לנסות עוד חמש דרכים.
בסוף להציע את הצעד הבא: "בוא נכיר את העסק שלך" (הסקיל business-profile).
