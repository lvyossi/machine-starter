# מצגת פשוטה

התוצר: `presentation.html` אחד בתיקיית פרויקט. כל שקופית היא `<section>`, עוברים ביניהן עם החצים, ושומרים כ-PDF דרך ההדפסה של הדפדפן.

## 1. תוכן קודם

לקרוא את `business.md` אם קיים (צבעים, פונט, שם העסק). לשאול:
- **למי המצגת ומה רוצים שהם יעשו בסוף?**
- **כמה זמן יש?** בערך שקופית לדקה או שתיים.

**להציג קודם רשימת שקופיות** — כותרת אחת לכל שקופית — ולקבל אישור לפני הבנייה.

## 2. כללי שקופית

- רעיון אחד לשקופית. עד 4 נקודות, כל נקודה עד שורה.
- כותרת שאומרת את המסקנה ("הלקוחות שלנו חוזרים — 70% מהם"), לא רק את הנושא ("לקוחות").
- מספר חשוב מקבל שקופית משלו, בגדול.
- שקופית אחרונה: מה מבקשים מהקהל לעשות.

## 3. בנייה

- `<html lang="he" dir="rtl">`, פונט עברי מ-Google Fonts, צבעים מ-`business.md`.
- כל שקופית `<section class="slide">` ביחס 16:9 (למשל 1280×720), ממורכזת ומוקטנת לגודל המסך.
- ניווט: חץ שמאלה או רווח = הבאה, חץ ימינה = הקודמת. מספר שקופית בפינה.
- הדפסה: `@media print` שבו כל שקופית היא עמוד (`@page { size: 1280px 720px; margin: 0 }`, `break-after: page`).
- טקסט גוף גדול מספיק לקריאה מהשורה האחרונה בחדר.

## 4. לבדוק ולמסור

- לפתוח בדפדפן ולעבור על כל השקופיות. לוודא ששום טקסט לא נחתך.
- להסביר למשתמש: חצים לניווט, F11 למסך מלא, Ctrl+P (או Cmd+P) → שמירה כ-PDF כדי לשלוח.
