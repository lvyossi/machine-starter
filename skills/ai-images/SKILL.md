# תמונות AI בחינם — Cloudflare

המשתמש כנראה לא מתכנת. לדבר בעברית פשוטה ולסכם, לא להדביק פלט ארוך.

**הסדר הנכון:** תמונות אמיתיות של העסק → תמונות מהמאגר (הסקיל `images`) → תמונת AI. תמונת AI מתאימה לרקעים, אווירה, חללים, מוצרים כלליים ואילוסטרציה. היא לא מתאימה לתמונה של העסק האמיתי, של הצוות או של עבודה שהעסק עשה (זה מטעה לקוחות).

## 1. בפעם הראשונה: חשבון חינמי ב-Cloudflare (5 דקות)

לבדוק אם כבר מחובר:
```bash
python3 "<תיקיית הסקיל>/make_image.py" --check
```
(בחלונות `python` במקום `python3`.) אם התשובה `OK` — לדלג לסעיף 2. אם `NO_KEY`:

1. להסביר במשפט: "Cloudflare נותנת בחינם מכסה יומית של תמונות AI, בערך 60 ביום. צריך חשבון ומפתח, פעם אחת."
2. לבקש מהמשתמש:
   - להירשם בחינם ב-https://dash.cloudflare.com/sign-up (בלי כרטיס אשראי) ולאשר את המייל.
   - בתפריט הצד: **AI** ← **Workers AI**. ללחוץ **Use REST API**.
   - שם רואים את **Account ID** (להעתיק), ולוחצים **Create a Workers AI API Token** ← **Create API Token** ← להעתיק את הטוקן (מוצג פעם אחת בלבד).
3. **לא לבקש שידביקו בצ'אט.** ליצור (או לפתוח) את `~/my-business/.env` ולהוסיף:
   ```
   CF_ACCOUNT_ID=<להדביק כאן את ה-Account ID>
   CF_API_TOKEN=<להדביק כאן את הטוקן>
   ```
   לפתוח את הקובץ (`open` במק, `notepad` בחלונות) ולבקש: "תדביק את שני הערכים במקום הטקסט, תשמור ותסגור, ותכתוב לי 'שמרתי'".
4. לוודא ש-`.env` רשום ב-`.gitignore` (שלא יעלה לאינטרנט). להריץ שוב `--check`.

אם עדיין `AUTH` — כנראה הטוקן הועתק חלקית או נוצר בלי הרשאת Workers AI. ליצור טוקן חדש באותו מסך.

## 2. לייצר

```bash
python3 "<תיקיית הסקיל>/make_image.py" "<תיאור באנגלית>" --size post --count 2 --name <נושא-קצר> --out images
```

- **התיאור באנגלית, מפורט:** מה רואים, איפה, איזו תאורה, מאיזו זווית. לקרוא את `business.md` אם קיים כדי להתאים לתחום ולסגנון. לתרגם בעצמך את הבקשה של המשתמש. דוגמה: "תמונה של פרגולה בחצר" → `Modern wooden pergola on a sunny Israeli backyard patio with outdoor sofa and potted plants, warm afternoon light`.
- הסקריפט מוסיף לבד: מראה של צילום אמיתי, ובלי טקסט, אותיות ולוגואים (המודל מייצר טקסט משובש).
- **גודל (`--size`):** `web` לדף ולאתר, `post` לפוסט 4:5, `story` לסטורי/ריל, `square` לפוסט מרובע, `deck` למצגת.
- **כמה:** ברירת מחדל 1. כשבוחרים — 2–3 גרסאות, לא יותר. כל תמונה ~10–20 שניות.
- `--seed 7` (מספר כלשהו) נותן תוצאה קבועה; לגרסה אחרת — מספר אחר.

התמונות נשמרות ב-`images/<נושא>-ai-01.jpg` וכו', ונרשמות ב-`images/sources.md` כ"נוצרה ב-AI".

## 3. להראות ולתקן

- לפתוח את התמונה ולהסתכל עליה בעצמך לפני שמראים: ידיים ואצבעות מעוותות, טקסט מזויף, אובייקטים מוזרים — אם יש, לייצר שוב עם תיאור מתוקן.
- להראות למשתמש ולשאול אם מתאים. תיקון = לשנות את התיאור ולייצר מחדש (אין "עריכה" של תמונה קיימת בסקיל הזה).

## 4. המכסה

- 10,000 "נוירונים" ביום בחינם. תמונה בגודל `post`/`web`/`story` ≈ 156 (כ-60 ביום), `square` ≈ 104 (כ-95 ביום).
- כשנגמר: הסקריפט כותב `QUOTA`. להגיד: "נגמרה המכסה של היום. היא מתאפסת בלילה (02:00–03:00). בינתיים אפשר תמונות מהמאגר." לא לפתוח חשבון בתשלום בלי שהמשתמש ביקש.
- אין חיוב אוטומטי: בחשבון החינמי, כשהמכסה נגמרת פשוט מקבלים שגיאה עד מחר.

## 5. כללים

- לא ליצור תמונה של אדם אמיתי מזוהה, של לקוחות, או "לפני/אחרי" מומצא.
- לא להציג תמונת AI כתמונה של העסק עצמו ("הפרויקט שלנו", "הקליניקה שלנו").
- בלי לוגואים ומותגים של אחרים.
- בפרסום ממומן במטא: אם התמונה מציגה אנשים או מצבים שנראים אמיתיים, לסמן שהיא נוצרה ב-AI לפי הדרישות של מטא.
