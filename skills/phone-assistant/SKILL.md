# עוזר בטלפון

קלוד קוד ממשיך לרוץ על המחשב, עם כל הקבצים והכלים, והמשתמש כותב לו מאפליקציית Claude בטלפון. זו אפשרות רשמית של Anthropic בשם Remote Control, כלולה במנוי (Pro ומעלה), בלי עלות נוספת.

**אם המשתמש ביקש "עוזר בוואטסאפ":** להסביר בקצרה שחיבור קלוד לוואטסאפ האישי דורש חיבור לא רשמי שעלול לגרום לחסימת המספר, ושהדרך הבטוחה היא אפליקציית Claude בטלפון. ואז להמשיך מכאן.

## 1. בדיקה לפני

- המשתמש מחובר עם מנוי Claude (Pro, Max או Team). עם מפתח API זה לא עובד. אם לא בטוחים, להריץ `/status`.
- בצוות (Team): בעל החשבון צריך להדליק Remote Control בהגדרות הניהול של Claude Code.
- אפליקציית Claude מותקנת בטלפון, מחוברת **לאותו חשבון** כמו במחשב. אם אין אפליקציה: להגיד למשתמש להריץ `/mobile`, שמציג QR שמוביל לחנות האפליקציות.

## 2. הפעלה

להגיד למשתמש לפתוח טרמינל, להיכנס לתיקיית העבודה ולהריץ:

```bash
cd ~/my-business
claude --remote-control "העסק שלי"
```

(בחלונות: `cd %USERPROFILE%\my-business`.) השם בגרשיים הוא השם שיופיע ברשימה בטלפון.

- בפעם הראשונה תופיע שאלה "Enable Remote Control?". עונים כן.
- אם כבר נמצאים בתוך שיחה של קלוד קוד: לכתוב `/remote-control` (או בקיצור `/rc`). אותו דבר עובד גם בתוסף של VS Code ובאפליקציית Claude למחשב.
- כדי שזה יידלק תמיד לבד: `/config` ← **Enable Remote Control for all sessions** ← true.

## 3. חיבור מהטלפון

- בטרמינל מופיעים קישור ו-QR. אם ה-QR לא מוצג, להריץ שוב `/remote-control` כדי לפתוח את מסך הסטטוס.
- סורקים את ה-QR עם המצלמה של הטלפון, והשיחה נפתחת באפליקציית Claude.
- אחר כך אפשר לחזור לשיחה מהאפליקציה בכל רגע: לשונית Code, והשיחה מופיעה ברשימה עם השם שנבחר.

**בדיקה ביחד:** לבקש מהמשתמש לכתוב מהטלפון "תגיד לי אילו קבצים יש בתיקייה", ולוודא שהתשובה מגיעה גם לטלפון וגם לטרמינל.

## 4. התראות לטלפון

כדי לקבל התראה כשמשימה נגמרת או כשקלוד צריך אישור:
1. לפתוח את אפליקציית Claude בטלפון ולאשר התראות.
2. במחשב: `/config` ← להדליק **Push when actions required**, ואם רוצים גם **Push when Claude decides**.
3. אפשר גם לבקש בטקסט: "תשלח לי התראה כשזה מוכן".

## 5. המחשב צריך להישאר דלוק

העוזר עובד רק כל עוד המחשב דלוק והטרמינל פתוח. אם המחשב נרדם או האינטרנט נופל, השיחה מתחברת מחדש לבד כשהמחשב חוזר. אבל אם סוגרים את הטרמינל, העוזר מפסיק לענות.

- **מק:** בחלון טרמינל נוסף להריץ `caffeinate -i`. המחשב לא יירדם כל עוד הפקודה רצה, ו-Ctrl+C מבטל. במחשב נייד צריך להשאיר את המכסה פתוח, או לחבר מסך חיצוני ומטען.
- **חלונות:** הגדרות ← מערכת ← צריכת חשמל ← "כשמחובר לחשמל, להעביר למצב שינה אחרי": **אף פעם**. ולהשאיר את המטען מחובר.
- **אם הטרמינל נסגר:** פותחים מחדש מאותה תיקייה, מריצים `claude --continue`, וכותבים `/rc`. השיחה ממשיכה מאיפה שהפסיקה.

## 6. מה לבקש מהטלפון

להציג למשתמש רשימה כזו, מותאמת לעסק שלו (לקרוא `business.md` אם קיים):

- "תשנה בדף את המחיר ל-X ותעלה לאוויר"
- "תוסיף לדף את התמונה הזו" ולצרף צילום מהטלפון. קלוד רואה את התמונה ושומר אותה בתיקייה
- "תכתוב פוסט על המבצע של השבוע"
- "תנסח תשובה ללקוח ששאל..." ולהדביק את ההודעה שלו
- "תכין הצעה קצרה ללקוח X" (עם כלי ההודעות או המצגת)
- "תבדוק אם הדף שלי עובד בטלפון"

**כלל:** בקשה אחת בכל הודעה, וכשהבקשה משנה משהו באוויר, לבקש קודם לראות את השינוי.

## 7. בטיחות

- כל מי שמחובר לחשבון Claude של המשתמש יכול לשלוט במחשב דרך העוזר. לא לשתף את החשבון.
- אפשר להוסיף שכבת אבטחה: ב-claude.ai, בהגדרות בעמוד Account, להדליק **Require trusted devices**. אחרי זה רק מכשיר מאומת (פנים או טביעת אצבע) יכול לשלוט בשיחה.
- את מה שקלוד מבקש לאשר מאשרים מהטלפון בדיוק כמו במחשב. לא לאשר בעיניים עצומות פעולות של מחיקה או העלאה לאוויר.
- השיחה נשמרת בשרתים של Anthropic כדי לסנכרן בין המכשירים. את הקבצים עצמם קלוד פותח ומריץ רק במחשב.

## 8. כשמשהו לא עובד

| מה רואים | מה עושים |
|---|---|
| "Remote Control requires a claude.ai subscription" | להתחבר מחדש עם `/login` לחשבון עם מנוי |
| "disabled by your organization's policy" | בחשבון Team: לבקש מבעל החשבון להדליק. בחשבון פרטי: `claude auth logout` ואז `claude auth login` |
| הטלפון מציג "Can't reach" | לבדוק שהמחשב ער ומחובר לאינטרנט. אם הטרמינל נסגר, לחזור לשלב 5 |
| השיחה לא מופיעה באפליקציה | לוודא שהטלפון והמחשב מחוברים לאותו חשבון, ולרענן את האפליקציה |

## 9. לסיים

לכתוב למשתמש בשלוש שורות: איך מפעילים בפעם הבאה (הפקודה מסעיף 2), איך שומרים על המחשב ער, ומה הבקשה הראשונה שכדאי לנסות מהטלפון.
