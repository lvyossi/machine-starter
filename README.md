# ⚡ קלוד משין — ערכת הפתיחה

10 כלים לבעלי עסקים, לעבודה עם קלוד קוד בעברית.

## מה בפנים

| כלי | מה הוא עושה | דוגמה לבקשה |
|---|---|---|
| **setup** | בודק ומכין את המחשב | "תכין לי את המחשב" |
| **business-profile** | קובץ "על העסק" שכל הכלים משתמשים בו | "תכיר את העסק שלי" |
| **landing-page** | דף נחיתה פשוט עם וואטסאפ וטופס | "תבנה לי דף נחיתה לשירות..." |
| **publish** | העלאה לאוויר עם קישור אמיתי | "תעלה את הדף לאוויר" |
| **social-post** | פוסטים לפייסבוק, אינסטגרם ולינקדאין | "תכתוב לי פוסט על..." |
| **messages** | מיילים והודעות וואטסאפ ללקוחות | "תכתוב פולואפ ללקוח ש..." |
| **faq** | שאלות ותשובות לאתר, לוואטסאפ ולגוגל | "תבנה לי שאלות נפוצות" |
| **competitor-research** | מחקר והשוואת מתחרים | "תבדוק את המתחרים שלי" |
| **presentation** | מצגת פשוטה, נשמרת כ-PDF | "תכין מצגת על העסק" |
| **data-insights** | ניתוח קובץ אקסל או CSV עם גרפים | "תנתח לי את קובץ המכירות" |

לא צריך לזכור שמות. מבקשים בעברית רגילה, והכלי המתאים מופעל לבד.

## איך מתחילים

1. "תכין לי את המחשב"
2. "תכיר את העסק שלי"
3. מכאן — כל בקשה.
